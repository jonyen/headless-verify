# headless-verify

A Claude Code plugin that makes Claude verify local web apps with short headless browser scripts
that print compact text, instead of step-by-step browser automation with screenshots. It ships
with a benchmark and a session analyzer that measure how many tokens the approach saves.

**Status:** design stage. The spec is in
[docs/superpowers/specs/2026-09-16-headless-verify-design.md](docs/superpowers/specs/2026-09-16-headless-verify-design.md).
Nothing is installable yet.
